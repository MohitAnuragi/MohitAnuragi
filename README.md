## Featured Projects

### SkinLens AI — Skin Analysis

An AI-powered skincare application that helps users understand their skin and build better skincare habits.

#### Key Features

- AI-powered skin analysis and personalized skincare guidance
- Skincare routines, skin insights, and progress tracking
- Built using Kotlin, Jetpack Compose, MVVM, Hilt, CameraX, Retrofit, Supabase, and Gemini AI

[View on Google Play](https://play.google.com/store/apps/details?id=com.skinlensai.skinlensai)

### Shayari Shaala

A Hindi and Urdu Shayari application with AI-powered content generation and a collection of poetry and quotes.

#### Key Features

- Reached 5K+ users/downloads
- Integrated Gemini AI for Shayari generation
- Organized content across multiple categories

[View on Google Play](https://play.google.com/store/apps/details?id=com.shayarishaala.shayarishaala)
